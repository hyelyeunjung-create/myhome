## 🚀 사용 방법

### 1. 로컬에서 실행
```bash
# 저장소 클론
git clone https://github.com/hyelyeunjung-create/myhome.git
cd myhome

# 간단한 로컬 서버로 실행 (Python 3)
python -m http.server 8000

# 또는 Node.js 사용
npx http-server
```

### 2. 프로필 사진 추가
1. 프로필 사진을 `profile.jpg`로 저장
2. 저장소의 루트 디렉토리에 배치
3. 또는 `index.html`의 `<img src="profile.jpg">` 부분을 이미지 경로로 수정

### 3. 배포

#### GitHub Pages로 배포
```bash
# 이미 GitHub 저장소에 push되어 있음
# Settings > Pages > Source를 "main" branch로 설정
# https://hyelyeunjung-create.github.io/myhome 에서 접속 가능
```

#### Netlify로 배포
1. Netlify에 로그인
2. "New site from Git" 선택
3. GitHub 저장소 연결
4. 배포 완료
